# CardProfitHunter V5.2.9

## Summary

V5.2.9 hardens the local eBay credential boundary for the private,
single-user controlled-demo baseline.

## Included

- Changes the `EbayCredentials` library default from production to sandbox
- Keeps production available only through an explicit environment value
- Writes OAuth token caches through an atomic temporary file and replacement
- Applies private `0700` directory and `0600` token-file permissions
- Repairs overly broad permissions when an existing valid cache is read
- Ignores malformed, non-object, missing-token, and non-string-token cache data
- Rejects symlinked cache directories and converts cache-write failures into a
  fixed sanitized `EbayApiError`
- Preserves an existing token cache when an atomic replacement fails and
  removes incomplete temporary files

## Safety Boundaries

This release does not change eBay request URLs for explicitly selected
environments, retry/backoff behavior, response normalization, search limits,
marketplace headers, card matching, valuation data, financial calculations,
dashboard filtering, database behavior, or CSV exports. No buying, bidding,
offering, seller-account, or listing mutation capability was added.
