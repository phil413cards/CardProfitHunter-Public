# CardProfitHunter V5.2.35

## Summary

V5.2.35 prevents uncut sheets, panels, strips, and promotional sheet products
from being treated as one specifically identified card.

## Included

- Excludes uncut card and trading-card sheets, panels, and strips
- Excludes sheets, panels, or strips containing multiple cards
- Excludes numeric multi-card panels and strips
- Excludes press, sell, proof, promo, sticker, tattoo, mini-card, souvenir, and
  generic card sheets
- Reuses the existing multi-card boundary in classification, search filtering,
  Scout ranking, and direct financial analysis
- Rechecks listing text at the final Scout boundary instead of trusting
  precomputed actionable metadata
- Applies an independent direct financial-engine veto even when an unsafe
  valuation keyword exactly repeats the sheet or panel wording
- Preserves printing plates, individual blank-back and artist-proof cards,
  named panel relic cards, and `Sheet Metal` inserts

## Safety Boundaries

This release changes sheet/panel/strip product detection only. It does not
change money formulas, valid single-card identity matching, eBay requests,
database behavior, CSV exports, dashboard filtering, stored user data, or
runtime configuration.
