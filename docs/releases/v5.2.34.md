# CardProfitHunter V5.2.34

## Summary

V5.2.34 expands authenticity filtering so additional unofficial and custom card
vocabulary cannot produce Scout or financial recommendations.

## Included

- Excludes `Unofficial`, `Not Licensed`, and `Non-Licensed` wording
- Excludes fan-made, fanmade, handmade, hand-made, and ORICA cards
- Excludes parody, AI-generated, artificial-intelligence-generated, concept,
  and aftermarket cards
- Reuses one shared custom/reproduction detector during classification, search
  filtering, Scout ranking, and direct financial analysis
- Rechecks listing text at the final Scout boundary instead of trusting
  precomputed actionable metadata
- Applies an independent direct financial-engine veto even when an unsafe
  valuation keyword exactly repeats the unofficial-card wording
- Preserves officially licensed, Fanatics-exclusive, hand-numbered,
  artist-proof, Fantasy Favorites, and other legitimate card wording

## Safety Boundaries

This release changes authenticity/custom-card detection only. It does not
change money formulas, valid authentic-card identity matching, eBay requests,
database behavior, CSV exports, dashboard filtering, stored user data, or
runtime configuration.
