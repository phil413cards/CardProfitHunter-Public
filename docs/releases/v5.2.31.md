# CardProfitHunter V5.2.31

## Summary

V5.2.31 prevents break participation and opening-service listings from being
treated as purchases of a specific raw card.

## Included

- Detects box, case, group, live, team, player, division, conference, and
  personal break listings
- Detects break spots, slots, entries, fillers, credits, auctions, streams,
  and services
- Detects player/team spots, pick-your-team/player formats, and `PYT`
- Detects rip-and-ship variants, live/group rips, and box/case/pack openings
- Removes affected listings during search relevance filtering and before Scout
  analysis
- Rechecks listing text at the final Scout boundary instead of trusting
  precomputed actionable metadata
- Applies an independent direct financial-engine veto even when an unsafe
  valuation keyword exactly repeats the break-service wording
- Preserves legitimate card names containing `Breakout`, `Breakaway`,
  `Record Breaking`, and `Unbreakable`

## Safety Boundaries

This release changes break-service detection only. It does not change money
formulas, valid raw-card identity matching, eBay requests, database behavior,
CSV exports, dashboard filtering, stored user data, or runtime configuration.
