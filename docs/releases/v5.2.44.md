# CardProfitHunter V5.2.44

## Summary

V5.2.44 fixes a search-quality defect found during the first structured
production beta review: package-only inventory explicitly stating that no card
is included can no longer reach Scout ranking.

## Included

- Classifies singular `package only` wording as non-card merchandise
- Rejects listing titles ending in `no card` or `no cards`
- Removes those listings before relevance scoring and Scout analysis
- Rechecks the same boundary inside Scout selection and financial analysis
- Preserves real cards with benign wording such as `Original Package Included`
  and `No Card Number Listed`

## Safety Boundaries

The observed listing already remained PASS and non-financial. This patch
strengthens discovery quality without changing money formulas, valuation
matching, recommendation thresholds, eBay requests, database behavior, or UI
behavior.
