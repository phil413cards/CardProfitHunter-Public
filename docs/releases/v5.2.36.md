# CardProfitHunter V5.2.36

## Summary

V5.2.36 adds a fail-closed seller-quality boundary before any financial BUY or
OFFER recommendation can be produced.

## Included

- Requires a nonempty seller username for financial recommendations
- Requires at least 100 seller feedback ratings
- Requires at least 99.0% positive seller feedback
- Treats missing pandas values as missing seller data without raising errors
- Rejects malformed, negative, fractional, boolean, nonfinite, and
  out-of-range seller metrics
- Accepts valid numeric-string values returned by normalized API or CSV inputs
- Preserves exact threshold values as eligible
- Clears matched valuation, profit, ROI, max-buy, sale-value, and suggested-offer
  fields when seller eligibility fails
- Applies the same seller boundary to raw-flip, PSA-grading, and BEST_OFFER paths

## Safety Boundaries

Seller return terms remain a required manual operator check for this private
controlled-demo baseline. This release does not add per-item eBay detail calls
or change return-policy handling, money formulas, valuation matching, eBay
requests, database behavior, CSV exports, dashboard filtering, stored user
data, or runtime configuration.
