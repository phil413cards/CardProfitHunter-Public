# CardProfitHunter V5.2.43

## Summary

V5.2.43 adds a structured, local beta-review workflow for measuring real-world
decision quality without changing recommendations or exposing private evidence.

## Included

- Adds a strict CSV schema for manually reviewed beta evidence
- Adds a read-only aggregate summarizer for false positives, false negatives,
  identity errors, money-model concerns, usefulness, and issue categories
- Adds a tracked header-only review template and owner-operated workflow guide
- Keeps completed review files under ignored `output/beta_reviews/`
- Limits local review inputs to 5 MB and 5,000 rows
- Rejects malformed, duplicate, missing, and unsupported review values
- Keeps listing references and notes out of aggregate command output and errors

## Safety Boundaries

This release does not call eBay, import or change the Streamlit app, write
SQLite, modify completed review files, set automatic launch thresholds, or
change card matching, scoring, money formulas, recommendations, dashboard
filtering, valuations, or application UI. Human verdicts are evidence labels,
not permission to buy, bid, or make offers.
