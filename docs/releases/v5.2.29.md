# CardProfitHunter V5.2.29

## Summary

V5.2.29 prevents multi-quantity card listings from appearing as single-card
Scout candidates or receiving financial recommendations.

## Included

- Excludes leading quantity multipliers such as `2x`, `3 X`, and `X2`
- Excludes `Qty`/`Quantity`, parenthesized counts, pairs, multiple copies, and
  numeric or word-based card counts
- Excludes mixed, bulk, assorted, and generic card lots plus set, bundle,
  collection, combo, and choose-multiple wording
- Removes affected listings during search relevance filtering and before Scout
  analysis
- Rechecks listing text at the final Scout boundary instead of trusting
  precomputed actionable metadata
- Applies an independent direct financial-engine veto even when an unsafe
  valuation keyword exactly repeats the multi-quantity wording
- Preserves explicit player-lot search behavior without allowing those rows to
  become Scout or financial recommendations
- Preserves single-card identity and descriptor phrases such as card `#2`,
  serial `1/2`, `2nd Year`, `2X MVP`, `Pick 2 Card`, and `Pair of Aces`

## Safety Boundaries

This release changes multi-card quantity detection only. It does not change
money formulas, valid single-card identity matching, eBay requests, database
behavior, CSV exports, dashboard filtering, stored user data, or runtime
configuration.
