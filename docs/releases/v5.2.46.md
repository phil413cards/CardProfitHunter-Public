# CardProfitHunter V5.2.46

## Summary

V5.2.46 removes ambiguity between unknown and explicitly free inbound shipping
and adds run traceability to generated search-result CSV files.

## Included

- Preserves missing, malformed, and invalid shipping as blank in analysis output
- Leaves total purchase price blank when required inbound shipping is unknown
- Preserves explicit free shipping as `0.0` with a valid total price
- Adds `search_query`, `application_version`, and `search_completed_at` to Live
  Search and Daily Buy Board CSV files and downloads
- Preserves each Daily Buy Board row's own saved-search query
- Uses the validated Live Search query that actually completed
- Prepares export-only copies without mutating displayed, session, or database data

## Safety Boundaries

Unknown shipping remains PASS and non-financial. Existing spreadsheet formula
injection protection remains active. This release does not change valuation
matching, profit formulas for eligible listings, recommendation thresholds,
eBay requests, credentials, database schema, or dashboard calculations.

## Verification

- 464 local `unittest` tests passed
- Python 3.11 and Python 3.12 GitHub Actions passed for both implementation pull
  requests
- Focused tests distinguish missing shipping from explicit free shipping
- Non-importing app tests verify file and download export traceability wiring
- `git diff --check` passed
- No live eBay call, credential access, real database write, or runtime-data
  change was performed during automated verification
