# CardProfitHunter V5.2.18

## Summary

V5.2.18 prevents non-card collectibles from being ranked as raw-card or
unverified Scout opportunities during live eBay searches.

## Included

- Requires positive trading-card evidence before a listing can enter a raw-card
  classification
- Filters ambiguous signed baseballs, numbered coins, photos, mini helmets, and
  books before Scout analysis
- Rechecks card evidence at the Scout recommendation boundary instead of
  trusting precomputed actionable flags alone
- Preserves valid Topps Chrome cards, National Treasures relics, on-card
  autographs, and recognized dual-card autograph listings
- Adds end-to-end regression coverage for classification, search relevance,
  Scout filtering, and spoofed metadata

## Safety Boundaries

Scout candidates remain discovery-only and non-financial. This release does not
change verified valuation matching, profit or ROI calculations, offer logic,
eBay request behavior, database behavior, or stored user data. Conservative
false negatives remain acceptable when a title does not provide enough evidence
that the item is a trading card.
