# CardProfitHunter V5.2.26

## Summary

V5.2.26 prevents listings with disclosed material card-condition defects from
appearing as Scout candidates or receiving financial recommendations.

## Included

- Expands hard defect detection to scratches, print lines, off-centering and
  `OC`, dents, dimples, edge or corner wear, soft or rounded corners, and corner
  dings
- Excludes disclosed surface issues, whitening, chipping, scuffing, peeling,
  staining, creasing, fading, and paper loss
- Applies defect detection to both title and normalized condition fields
- Removes affected rows during search relevance filtering and before Scout
  analysis
- Rechecks listing text at the final Scout boundary instead of trusting
  precomputed actionable metadata
- Applies an independent direct financial-engine veto even when an unsafe
  valuation keyword exactly repeats the defect wording
- Preserves explicit no-defect statements such as `No Damage`, `No Scratches`,
  `No Print Lines`, `Not Trimmed`, `Damage Free`, and `Scratch Resistant`

## Safety Boundaries

This release changes disclosed-condition eligibility only. It does not infer
condition from photos, alter money formulas, loosen valid card identity
matching, call eBay differently, change persistence, or modify stored data.
