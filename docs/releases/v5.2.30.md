# CardProfitHunter V5.2.30

## Summary

V5.2.30 expands graded-card detection so third-party slabs cannot be treated as
raw-card or raw-to-grade opportunities.

## Included

- Centralizes grading-company labels and grade parsing in one shared helper
- Recognizes compact, spaced, and hyphenated grades from PSA, BGS, SGC, CGC,
  TAG, HGA, CSG, GMA, ISA, KSA, AGS, MNT, FCG, BVG, and BCCG
- Recognizes Beckett, Arena Club, Rare Edition, and Degree Grading names
- Excludes generic `graded`, `professionally graded`, `slab`, `slabbed`,
  `encapsulated`, `gem mint`, and `mint 10` wording
- Applies the same boundary in parsing, listing classification, Scout ranking,
  and direct financial analysis
- Rechecks listing text at the final Scout and financial boundaries rather than
  trusting precomputed metadata
- Prevents an exact unsafe valuation keyword from bypassing slab detection
- Preserves legitimate raw-card text such as the player Josh Beckett, Panini
  Certified, an HGA insert name without a grade, and anniversary numbering

## Safety Boundaries

This release changes grader/slab detection only. It does not change money
formulas, valid raw-card identity matching, eBay requests, database behavior,
CSV exports, dashboard filtering, stored user data, or runtime configuration.
