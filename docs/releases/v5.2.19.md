# CardProfitHunter V5.2.19

## Summary

V5.2.19 closes a test-discovery gap so every intended regression test runs
under the repository's canonical standard-library `unittest` command.

## Included

- Converts four legacy pytest-style modules to discoverable
  `unittest.TestCase` tests
- Brings 19 previously skipped parser, classifier, recommendation, and search
  relevance tests into normal local and CI execution
- Adds an AST-based regression guard that fails if a module-level `test_*`
  function could be silently skipped in the future
- Keeps pytest out of the supported workflow and adds no dependency

## Safety Boundaries

This release changes tests and release documentation only. It does not change
application behavior, card matching, scoring, recommendation logic, money math,
eBay requests, database behavior, validation, exports, or stored user data.

## Verification

- 330 local `unittest` tests passed
- Isolated Streamlit startup smoke test passed without network or real runtime
  state
- Tracked private runtime artifact guard passed
- `git diff --check` passed
- No live eBay call, credential access, real database write, or runtime-data
  change was performed
