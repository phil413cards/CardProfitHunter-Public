# CardProfitHunter V5.2.45

## Summary

V5.2.45 makes Scout discovery honor explicit card-identity terms in the user's
search. A search for a specific year, product, card number, parallel, rookie,
or autograph can no longer return conflicting or insufficiently identified
Scout candidates.

## Included

- Enforces explicit query year, manufacturer, product, and card number
- Enforces explicitly requested parallel, rookie, and autograph identity
- Rejects listings that conflict with or omit those requested identity terms
- Records stable query-identity rejection reasons at the Scout boundary
- Preserves broad player-only discovery behavior
- Covers the five false-positive candidates observed in the V5.2.44 beta run

## Safety Boundaries

Rejected listings remain PASS and non-financial. This release does not change
money formulas, valuation matching, recommendation thresholds, eBay requests,
database behavior, credentials, or application UI behavior.
