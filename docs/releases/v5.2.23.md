# CardProfitHunter V5.2.23

## Summary

V5.2.23 prevents unauthentic, custom, and materially altered listings from
appearing as card opportunities or receiving financial fields.

## Included

- Expands custom/reprint classification to replica, reproduction, repro,
  unlicensed, unauthorized, fan-art, ACEO, novelty, homemade, counterfeit,
  fake, and bootleg wording
- Expands damaged-card classification to trimming, alteration, restoration,
  added color, evidence of trimming, and minimum-size disclosures
- Removes both categories during search relevance filtering and before Scout
  analysis
- Reclassifies at the final Scout boundary to reject spoofed actionable
  metadata
- Blocks every covered term in direct financial analysis before valuation,
  profit, ROI, max-buy, or offer fields can attach
- Preserves legitimate image variations, relic cards, and mini-card wording

## Safety Boundaries

This release adds authenticity and condition eligibility checks only. It does
not change valid card identity matching, money formulas, eBay requests,
database behavior, validation, exports, or stored user data.
