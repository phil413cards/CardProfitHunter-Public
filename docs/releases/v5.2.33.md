# CardProfitHunter V5.2.33

## Summary

V5.2.33 prevents choose-your-card and variation-menu inventory from being
treated as a purchase of one specifically identified card.

## Included

- Detects `U Pick`, `You Pick`, `You Choose`, and `You Select`
- Detects pick/choose/select-your-card and pick/choose/select-one wording
- Detects list, menu, and dropdown selection instructions
- Detects card-of-your-choice, complete-your-set, per-card pricing,
  individually sold cards, one-card-per-order, separately sold cards, and
  multiple-cards-available wording
- Removes affected listings during search relevance filtering and before Scout
  analysis
- Rechecks listing text at the final Scout boundary instead of trusting
  precomputed actionable metadata
- Applies an independent direct financial-engine veto even when an unsafe
  valuation keyword exactly repeats the choice-menu wording
- Preserves established search-facing exclusion reasons
- Preserves legitimate identity wording such as `Pick 2 Card`, First Overall
  Pick, Draft Picks, Photo Variation, Choice parallels, and Panini Select

## Safety Boundaries

This release changes choice-listing detection only. It does not change money
formulas, valid single-card identity matching, eBay requests, database behavior,
CSV exports, dashboard filtering, stored user data, or runtime configuration.
