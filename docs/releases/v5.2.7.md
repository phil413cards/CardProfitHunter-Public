# CardProfitHunter V5.2.7

## Summary

V5.2.7 packages repository-governance and launch-interface safety improvements
for the private, local-only controlled-demo baseline.

## Included

- Adds a pull-request safety checklist covering scope, private runtime
  artifacts, mocked eBay activity, temporary databases, valuation evidence,
  financial-action boundaries, and required verification
- Records the current private-repository governance state and the unavailable
  branch-protection control on the present GitHub plan
- Sources the Streamlit page title and visible application version from
  `VERSION` instead of stale hard-coded V5.1 branding
- Removes unfinished Inventory Manager and PSA Pipeline promises from the
  launch dashboard
- Requires explicit, record-scoped confirmation before deleting saved searches
  or watchlist items
- Preserves the non-overwriting `.env` setup command and reconciles prior
  release-only `main` history into `develop`

## Safety Boundaries

This release does not change card matching, valuation math, scoring, eBay API
behavior, dashboard financial filtering, SQLite schema, or stored user data.
It does not make the application hosted or multi-user ready. The repository
remains private because its pre-sanitization history has separately documented
privacy risk.
