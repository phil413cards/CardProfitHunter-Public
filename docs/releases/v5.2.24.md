# CardProfitHunter V5.2.24

## Summary

V5.2.24 makes common autograph terminology consistent across card discovery,
classification, and parsed identity metadata while preserving conservative
financial matching.

## Included

- Recognizes `auto`, `autograph`, `autographs`, `autographed`, and `signed`
  card wording as autograph evidence
- Classifies explicit autographed and signed cards as raw autograph listings
  when other card-evidence and eligibility checks pass
- Sets the parsed autograph signal for the same terminology
- Removes autograph modifiers from parsed player-search identity
- Treats `autographed` and `signed` as hard valuation-identity variants instead
  of harmless presentation words
- Preserves exact same-wording matches while keeping generic signed wording
  distinct from manufacturer-autograph valuations

## Safety Boundaries

This release changes autograph terminology handling only. It does not change
money formulas, valuation provenance, eBay requests, database behavior,
validation, exports, dashboard filtering, or stored user data. Conservative
false negatives remain acceptable when autograph provenance is unclear.
