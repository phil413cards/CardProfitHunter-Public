# CardProfitHunter V5.2.40

## Summary

V5.2.40 makes upcoming verified-valuation expiry dates visible in the app so
the current private-demo valuation set can be refreshed before it becomes
non-actionable.

## Included

- Shows a warning when verified valuations expire within 30 days
- Reports the number of valuations requiring renewal without exposing or
  changing their financial fields
- Labels affected rows as `Due soon` in the Card Values editor
- Preserves verified valuation actionability through the configured expiry
  date
- Keeps the computed freshness label out of the persisted valuation CSV
- Adds non-importing app-wiring regression coverage for the renewal warning

## Safety Boundaries

This release does not change valuation prices, provenance, expiry dates, card
identity matching, money formulas, recommendations, eBay requests, database
schema, dashboard financial filtering, or the local-only single-user operating
boundary. Expired, missing-provenance, invalid-provenance, demonstration, and
unverified valuations retain their existing non-actionable behavior.

- Valuation-renewal and non-importing app-wiring regressions passed
- Existing engine, eBay, dashboard, database, validation, and startup suites

- Tracked private runtime artifact guard passed
- `git diff --check` passed
- No live eBay call, credential access, real database write, or runtime-data
