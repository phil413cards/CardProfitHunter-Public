# CardProfitHunter V5.2.22

## Summary

V5.2.22 prevents redemption, rewards-points, and code-only products from being
treated as collectible-card opportunities.

## Included

- Adds a dedicated non-actionable classification for redemption listings,
  Panini/rewards/wild-card points, points cards, and code cards
- Excludes digital, unused, scratched, and QR codes plus Home Run Challenge code
  products from search and Scout analysis
- Rechecks those product types at the final Scout boundary
- Adds direct financial-engine blocking before any valuation, profit, ROI,
  max-buy, or suggested-offer field can attach
- Adds table-driven classification, relevance, Scout, spoofed-metadata, and
  direct-analysis regression coverage

## Safety Boundaries

This release adds product eligibility checks only. It does not change valid
card identity matching, money formulas, eBay requests, database behavior,
validation, exports, or stored user data.
